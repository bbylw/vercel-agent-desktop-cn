先跑这三条，把「环境是否就绪」和「命令是否写错」分开判断：

```bash
agent-desktop status              # 平台、权限、支持的界面
agent-desktop permissions         # 权限是否给到位（macOS 尤其容易漏）
agent-desktop list-apps           # 目标应用是否真的在运行
```

读不到界面最常见的原因不是命令写错，而是权限没给、或者这个应用压根没有发布可访问性树。
`status` 里的权限状态不正常时，先解决权限再往下走。
